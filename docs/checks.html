UI library checks

The same checks, run on iOS and Android for every app, side by side. Generated from results/ by scripts/report-html.mjs. All apps build the same test screen. iOS: Release builds on an iPhone 17 simulator running iOS 27.0. Android: Release builds on the Samsung Galaxy A15 5G (SM-A156E) running Android 16 (API 36). The accessibility checks read the tree each screen reader is given (VoiceOver on iOS, TalkBack on Android); they don't hear what it says. Hover a result for the measured detail.
