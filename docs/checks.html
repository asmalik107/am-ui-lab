UI library checks

Every check run on every app, generated from results/ by scripts/report-html.mjs. All apps build the same test screen; results are from Release builds on an iPhone 17 simulator running iOS 27.0. The accessibility checks read the iOS accessibility tree, which is what VoiceOver is given. They don't hear what it says. Hover a cell for the measured detail.

✓ pass✗ fail– not applicable (the app has no such element)* NativeWind results use a line-height workaround; see apps/nativewind/NOTES.md
