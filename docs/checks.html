Every check run on every app, generated from results/ by scripts/report-html.mjs. All apps build the same test screen; results are from Release builds on an iPhone 17 Pro simulator running iOS 26.4. The accessibility checks read the iOS accessibility tree, which is what VoiceOver is given. They don't hear what it says. Hover a cell for the measured detail.
